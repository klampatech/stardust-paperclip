# FUL-35a: WASM Core Integration

## Overview

This document describes the WASM (WebAssembly) integration for the Falling Sand simulation, enabling high-performance physics calculations in the browser.

## WASM API Surface

### Simulation Class

```rust
#[wasm_bindgen]
pub struct Simulation {
    grid: ChunkedGrid,      // Optimized spatial partitioning
    simulator: Simulator,   // Physics engine
    width: usize,
    height: usize,
    pixel_cache: Vec<u8>,   // Pre-allocated for zero-allocation
}
```

### Exposed Methods

| Method | Signature | Description |
|--------|-----------|-------------|
| `new` | `(width, height) -> Simulation` | Create simulation with clamped dimensions |
| `tick` | `() -> void` | Run one physics tick |
| `tick_many` | `(count) -> void` | Run N physics ticks |
| `spawn` | `(x, y, material) -> bool` | Spawn single particle |
| `spawn_brush` | `(cx, cy, material, radius) -> count` | Circular brush spawn |
| `get_material` | `(x, y) -> string` | Get material at position |
| `get_lifetime` | `(x, y) -> u32` | Get particle lifetime |
| `particle_count` | `() -> usize` | Total active particles |
| `width` | `() -> usize` | Grid width |
| `height` | `() -> usize` | Grid height |
| `clear` | `() -> void` | Reset simulation |
| `render_rgba` | `() -> Uint8Array` | Render to pixel buffer |
| `render_rgba_direct` | `() -> void` | Render to cached buffer |
| `take_pixel_buffer` | `() -> Uint8Array` | Zero-copy buffer transfer |

## Performance Optimizations

### 1. ChunkedGrid Spatial Partitioning
- 64x64 pixel chunks for cache locality
- O(1) neighbor lookups via spatial hash
- Dirty chunk tracking for efficient updates

### 2. Pre-allocated Pixel Buffers
- Avoids allocation on every render frame
- `pixel_cache` reused across frames
- Zero-copy transfer via `take_pixel_buffer()`

### 3. Circular Brush Spawning
- Single function for brush operations
- Bounded radius (max 50) to prevent DoS
- Returns spawn count for UI feedback

### 4. Material Dimension Clamping
- Width/height capped at 1000x1000
- Prevents memory exhaustion
- ~4MB max pixel buffer size

## Usage in React

```typescript
import { initWasm, createWasmSimulation } from './wasm';

async function init() {
  await initWasm();
  
  const sim = createWasmSimulation(200, 200);
  if (sim) {
    sim.spawn(100, 100, 'sand');
    sim.spawn_brush(100, 50, 'water', 10);
    
    // Game loop
    function update() {
      sim.tick();
      const pixels = sim.render_rgba();
      // Draw to canvas...
      requestAnimationFrame(update);
    }
    update();
  }
}
```

## Fallback Strategy

If WASM fails to initialize:
1. Log warning to console
2. Use existing JS `SimulationCanvas` implementation
3. All interactions continue via normal canvas rendering
